# Launch Checklist

## Content approval

- [ ] All page copy is fact-checked and approved.
- [ ] Missing or conflicting information is resolved or explicitly deferred.
- [ ] Important information from flyers is represented as real website text.
- [ ] Dates, prices, ages, schedules, policies, and credentials are verified where shown.

## Links and Studio Pro

- [ ] Every Studio Pro link is recorded in `studio-pro-links.md`.
- [ ] Every call to action reaches the intended destination.
- [ ] Desktop and mobile link behavior is tested.
- [ ] No private or credential-bearing URLs are present.

## Responsive QA

- [ ] Desktop layouts reviewed.
- [ ] Tablet layouts reviewed.
- [ ] Mobile layouts reviewed.
- [ ] Navigation and touch targets are usable at each breakpoint.
- [ ] Text remains readable without clipping or overflow.

## Accessibility and media

- [ ] Heading hierarchy is logical.
- [ ] Color contrast is acceptable.
- [ ] Images have useful alt text or are marked decorative.
- [ ] Selected media is optimized and usage is approved.
- [ ] Important text is not embedded only in images.

## Operational readiness

- [ ] Contact and location details are verified.
- [ ] Forms and notifications are tested by the responsible owner.
- [ ] SEO titles and descriptions are reviewed.
- [ ] Favicon and social sharing image are set.
- [ ] Domain and analytics responsibilities are confirmed.
- [ ] Backup/rollback approach is confirmed before publishing.
