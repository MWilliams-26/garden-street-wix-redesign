## Shared content rules

- Use the header and footer defined in `wix/header-navigation.md`.
- End every major page with a specific Studio Pro action. A page-specific inquiry may appear earlier but does not replace the final Studio Pro callout.
- Repeat essential flyer information as searchable webpage text.
- Use only image placements that pass `docs/photo-publication-check.md` and descriptive, non-identifying alt text.
- Show schedules only as parent guidance; Studio Pro is authoritative for current availability.
- On mobile, keep the page purpose and first useful action above decorative galleries or long biographies.
