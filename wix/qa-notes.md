## QA coverage

### Content

- [ ] Approved copy matches the page documents.
- [ ] No unsupported facts or outdated placeholders appear.
- [ ] Important flyer content is available as real text.

### Links and actions

- [ ] Internal navigation works.
- [ ] Studio Pro links match the registry and intended purpose.
- [ ] Contact actions and forms work.
- [ ] External destinations use the approved same/new-tab behavior and are identified clearly.
- [ ] Logged-out Studio Pro flows match each button label.

### Responsive behavior

- [ ] Desktop reviewed.
- [ ] Tablet portrait and landscape reviewed.
- [ ] Small and large mobile sizes reviewed.
- [ ] No clipping, overlap, unexpected wrapping, or horizontal scrolling.

### Accessibility and usability

- [ ] Keyboard navigation and focus states work.
- [ ] Touch targets are comfortable.
- [ ] Contrast and text sizing are readable.
- [ ] Images have appropriate alt text.
- [ ] Motion and media controls are appropriate.
- [ ] Heading order is logical and each page has one H1.
- [ ] Page titles and meta descriptions match approved content.
- [ ] Forms use persistent labels, understandable errors and a success message.
- [ ] Layout remains usable at 200% browser zoom without horizontal scrolling.

### Image safety

- [ ] Every child image has documented client approval and media-release confirmation.
- [ ] No student names appear in alt text or captions without separate approval.
- [ ] No internal-only competition material or source metadata is exposed.
- [ ] Hero and gallery crops preserve subjects on desktop, laptop, tablet and mobile.

### Wix Editor constraints

- [ ] The build uses the existing Wix Editor duplicate, not Wix Studio-only controls.
- [ ] Desktop elements remain inside appropriate gridlines.
- [ ] Mobile Editor order matches parent-task priority.
- [ ] Tablet portrait and landscape are recorded as verification outcomes.
- [ ] Premium Lite supports every selected gallery, form and integration feature.
