# Homepage Build Plan

## Build status and rules

This plan is for manual construction in the existing Wix Editor duplicate on Premium Lite. It does not authorize publication or connect this repository to Wix. Build with standard Wix strips/sections, text, buttons, simple columns, repeaters and galleries. Confirm plan availability before choosing a premium app or feature.

All child photography is **candidate-only** until the client confirms public website media releases. Remaining local photos must not be copied or optimized until the proposed shortlist is approved. Paths beginning with `assets/` below describe web-ready files documented inside the read-only expanded client archive; reconcile them into the root asset library only after approval.
